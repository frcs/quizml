LaTeX to MathML Engine Comparison

An interactive side-by-side evaluation of make4ht (TeXLive), Pandoc (Haskell/texmath), and latex2mathml (Pure Python) rendering native MathML across browser layout, typographical precision, XML bloat, and execution latency.

1. make4ht (TeX4ht / TeXLive) Runs full TeXLive engine. Supports preambles/macros. Outputs Presentation MathML 2/3 with TeX4ht comments and CSS classes. ~1.5s/batch.
2. Pandoc (texmath CLI) Industry document standard. Generates modern MathML Core with accessible LaTeX <annotation>. Supports OMML for Word. ~0.03s/eq.
3. latex2mathml (Pure Python) Zero external dependencies. Compact, standards-compliant Presentation MathML. Instantaneous execution (~0.0002s/eq).
