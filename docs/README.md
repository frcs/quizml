# QuizML  <!-- {docsify-ignore} -->

QuizML converts quizzes written in YAML and Markdown into Blackboard imports,
HTML previews, LaTeX documents, PDFs, and other configured outputs.

Start with the [quick start](quickstart.md), then use the guides below to learn
about authoring quizzes and configuring outputs.

- [Command-line usage](usage.md)
- [Quiz YAML syntax](syntax_yaml.md)
- [Question types](syntax_questions.md)
- [Configuration and targets](configuration.md)
- [Writing templates](writing_templates.md)
- [Schema validation](schema_validation.md)

The [project README](https://github.com/frcs/quizml#readme) includes a sample
quiz and a preview of the generated output.
