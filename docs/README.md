# QuizML documentation <!-- {docsify-ignore} -->

QuizML converts quizzes written in YAML and Markdown into configured outputs,
including Blackboard imports, HTML previews, Word documents, QTI packages,
Moodle XML, and LaTeX sources or PDFs.

New to QuizML? Start with the [Quick start](quickstart.md). Then explore:

- **Writing quizzes**: [Quiz structure](syntax_yaml.md), [Header fields](syntax_header.md),
  [Question types](syntax_questions.md), [Markdown and equations](syntax_md.md),
  [Question layout](question_layout.md), and [Question banks](module_workflow.md).
- **Command-line usage**: [Compile, format, sample, diff, and pin quizzes](usage.md).
- **Configuration**: [Project setup](configuration.md), [Targets](targets.md),
  [Templates](writing_templates.md), and [Schema validation](schema_validation.md).

Use the sidebar navigation to browse the complete guide and [changelog](changelog.md).
